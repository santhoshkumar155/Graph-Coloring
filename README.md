# Graph Coloring using Backtracking

## 📌 Description
This project solves the Graph Coloring Problem using Backtracking algorithm.

## 🎯 Objective
To color a graph with 7 nodes using 3 colors such that no adjacent nodes share the same color.

## 🧠 Algorithm Used
Backtracking

## ⚙️ Features
- Uses adjacency matrix
- Recursive approach
- Constraint checking (isSafe function)

## ▶️ How to Run
1. Install Python
2. Run:
   python graph_coloring.py

## 📤 Output
Displays valid color assignment for each node

## 📚 Concepts Used
- Backtracking
- Recursion
- Graph Theory
